## 자문 요청 컨텍스트

**의뢰 issue**: PACAA-743 (리뷰 가져오기 시스템 검토)
**의뢰 SG/Goal**: SG-1 (Vendor coverage) — vendor trust signal 강화 차원
**결정 deadline**: 본 wake 내 검토 후 보드에 옵션 surface

## 보드의 원 아이디어

다나와 모델에서 착안. 각 vendor 자사 웹사이트(또는 vendor 가 입점한 쇼핑몰 페이지, ex: 스마트스토어/쿠팡/11번가/자사몰)에 게재된 고객 리뷰를 **스크래핑**하여 Packlinx 의 vendor 페이지에 그대로(또는 변형하여) **재게시**하는 시스템.

## 구체 자문 질문

각 시나리오별 법적 risk 등급 (`낮음/중간/높음/금지`) + 법률 조문 인용 + 위반 시 sanction 규모 부탁드립니다.

### 시나리오 A — 원문 그대로 재게시
vendor 의 자사 사이트 또는 입점 마켓(스마트스토어 등) 리뷰를 **HTML 본문 + 작성자 닉네임 + 별점 + 날짜** 그대로 Packlinx vendor 페이지에 표시.

### 시나리오 B — 익명화 + 요약 재게시
작성자 닉네임 제거, 별점·날짜·키워드만 추출, 텍스트는 LLM 으로 요약·재작성한 결과물을 표시.

### 시나리오 C — 메타데이터만 (집계)
리뷰 텍스트 표시 없이 **평균 별점 + 리뷰 개수 + '리뷰 보러 가기' 링크(원문 사이트로 outbound)** 만 표시.

### 시나리오 D — 스크래핑 자체의 합법성
위 3 시나리오와 별개로 **자동화된 크롤링 행위 자체** (스마트스토어/쿠팡/자사몰 robots.txt 또는 약관에 anti-bot 조항이 있는 경우 포함) 의 위법성. 특히 정보통신망법 §48 (정당한 접근권한 없는 정보처리 침해) 및 컴퓨터프로그램보호법 적용 여부.

## 관련 법령 (자문 시 검토 부탁)

- 저작권법 §4 (저작물 정의 — 리뷰가 저작물인가), §35-3 (공정이용)
- 저작권법 §93 (DB 제작자의 권리) — 스마트스토어 등의 review DB 침해 여부
- 부정경쟁방지법 §2-1-(파) — 성과물 무단사용 (네이버 vs 인크루트, 잡코리아 vs 사람인 등 판례 적용)
- 개인정보보호법 §15·§17·§39-3 — 리뷰어 닉네임/구매정보가 개인정보 해당 여부, 정보주체 동의 없는 처리
- 표시광고법 §3 (부당한 표시·광고) — 타사 리뷰를 Packlin
