## 자문 요청 배경

[PACAA-766](/PACAA/issues/PACAA-766) Vendor trust signal 축 강화 작업의 일환으로, P5.4 카테고리 in-depth 가이드에 "믿을 수 있는 [카테고리] 업체 확인하는 법" 섹션을 추가할 예정입니다.

이 섹션은 packlinx.com 외부에서 검색 가능한 신규 콘텐츠 (Surface 1) 에 해당하므로, 표시광고법 및 저작권 관점 법적 자문이 필요합니다.

## 검토 요청 콘텐츠 내용

각 P5.4 카테고리 가이드에 추가되는 섹션:
1. 사업자등록번호 확인 안내 (국세청 공개 조회 링크 제공)
2. KS/KC 인증번호 확인 안내 (공개 인증 DB 링크 제공)
3. 납품실적/주요 납품처 업체 자기 신고 정보 표시
4. Packlinx 확인 배지 (staff 검증 완료 업체 표시)

## 검토 필요 항목

- [ ] 국세청/KFTC 공개 DB 링크 제공 시 표시광고법 이슈 여부
- [ ] 업체 자기 신고 납품실적 표시 시 허위광고 / 부정경쟁방지법 노출 여부
- [ ] "Packlinx 확인 배지" 명칭 사용 시 오해 소지 (정부 인증으로 오인 가능성)
- [ ] KS/KC 인증번호 표시 + 공개 링크 제공의 저작권/무단 사용 이슈 여부
